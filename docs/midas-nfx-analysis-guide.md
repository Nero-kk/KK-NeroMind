# Midas NFX 활용 해석 역량 향상 가이드 (구조 · 유동 · 열해석)

> 목적: ANSYS가 아닌 **Midas NFX** 환경에서 구조(Structural), 유동(CFD), 열(Thermal) 해석
> 실무 역량을 **빠르고 실용적으로** 끌어올리기 위한 단계별 학습 계획.
> 대상: 해석을 처음 또는 다시 체계적으로 익히려는 엔지니어/연구자.

---

## 0. 전체 학습 전략 (먼저 읽기)

### 핵심 원칙
1. **"작게 만들고, 검증하고, 키운다"** — 처음부터 실제 제품 모델로 시작하지 않는다.
   해석값을 손계산/이론해와 비교할 수 있는 **단순 벤치마크 모델**부터 만든다.
2. **결과를 항상 검증한다** — 메시 수렴(Mesh Convergence), 단위 일관성, 경계조건 타당성을
   매 해석마다 점검하는 습관을 들인다. (해석은 "돌리는 것"이 아니라 "믿을 수 있게 만드는 것")
3. **이론 30% + 손 70%** — 책만 보지 말고 NFX를 직접 조작하며 학습한다.
4. **한 분야 = 한 노트** — 각 해석을 마인드맵/노트로 기록(이 가이드를 KK-NeroMind로 정리 추천).

### Midas NFX 환경 사전 점검 (Day 0)
- [ ] 라이선스 종류 확인: **NFX Structural / CFD / 통합판** 중 보유 모듈 파악
- [ ] 단위계 설정 통일 — 권장: **SI (N, mm, MPa, ton, s)** 또는 (N, m, Pa, kg, s)
  - mm 단위계 사용 시 밀도/물성 단위 환산에 특히 주의 (가장 흔한 실수)
- [ ] 솔버 설정 위치 숙지: `Analysis → Analysis Case → Solver Option`
- [ ] 결과 후처리 도구 위치: `Results → Contour / Probe / Graph`
- [ ] 학습 자료 확보:
  - Midas NFX 공식 **Online Manual / Tutorial** (Help 메뉴 내장)
  - MIDAS **NFX 웨비나 / e-Learning** (midasuser, MIDAS NFX YouTube 채널)
  - **Verification Manual** (이론해 vs 해석 비교 예제 — 가장 실용적)

### 공통 워크플로 (모든 해석에 동일)
```
① 형상(Geometry)  →  ② 물성(Material)  →  ③ 메시(Mesh)
   →  ④ 경계조건/하중(BC/Load)  →  ⑤ 해석조건(Analysis Case)
   →  ⑥ 솔버 실행(Solve)  →  ⑦ 후처리/검증(Post & Verify)
```

## 1. 구조 해석 (Structural Analysis)

가장 진입장벽이 낮고 검증이 쉬워 **첫 번째로 학습할 분야**.

### 1.1 반드시 알아야 할 개념
| 개념 | 설명 | 검증 포인트 |
|------|------|-------------|
| 요소 종류 | 1D(beam/rod), 2D(shell), 3D(solid) | 형상 두께/비율로 선택 |
| 선형 정적 | 작은 변형, 선형 탄성 | 응력 < 항복강도 확인 |
| 메시 수렴 | 메시 조밀화 시 응력 수렴 | 변화율 < 5% |
| 응력 종류 | von Mises, Principal, Tresca | 연성/취성 재료 구분 |
| 특이점 | 날카로운 코너의 응력 발산 | 필렛 적용 / 핫스팟 무시 |

### 1.2 단계별 학습 계획 (약 3주)

**Week 1 — 기초 정적 해석 (Linear Static)**
- Day 1–2: 외팔보(Cantilever Beam) 굽힘 해석
  - 손계산: `δ = PL³/3EI`, `σ = Mc/I` 와 NFX 결과 비교 (오차 5% 이내 목표)
- Day 3: 메시 수렴 스터디 — 요소 크기 4단계로 줄이며 최대응력 그래프 작성
- Day 4: Solid vs Shell vs Beam 동일 모델 비교 → 요소 선택 감각 익히기
- Day 5: 접촉(Contact) 기초 — 두 부품 압축 / Bonded vs Sliding

**Week 2 — 실전 경계조건과 하중**
- 볼트 체결부(Bolt Pretension), 압력하중, 원격하중(Remote Load)
- 대칭조건(Symmetry)으로 모델 축소 → 해석 시간 단축 실습
- 모달 해석(Modal/Eigenvalue): 고유진동수 추출, 이론식과 비교

**Week 3 — 비선형 & 응용**
- 기하 비선형(대변형), 재료 비선형(소성, Bi-linear)
- 좌굴(Buckling) 해석
- 피로(Fatigue) 기초 (NFX Fatigue 모듈 보유 시)
- **종합 과제**: 실제 브래킷/프레임 1개를 처음부터 끝까지 + 보고서 작성

### 1.3 실용 팁
- 응력 특이점은 무시하거나 필렛으로 처리 — 메시 줄여도 응력이 계속 커지면 특이점 의심
- 변형 형상(Deformed Shape)을 **과장 배율**로 먼저 확인 → BC 오류 즉시 발견
- 반력(Reaction Force) 합 = 외력 합 인지 확인 → 평형 검증

## 2. 유동 해석 (CFD / Flow Analysis)

NFX CFD는 유한체적법(FVM) 기반. 구조보다 메시·수렴 난이도가 높아 **두 번째 학습**.

### 2.1 반드시 알아야 할 개념
| 개념 | 설명 | 실무 체크 |
|------|------|-----------|
| 레이놀즈 수 (Re) | 층류/난류 판단 | Re로 모델 선택 |
| 난류 모델 | k-ε, k-ω SST | 벽면 박리 있으면 SST |
| 경계층 메시 | 벽 근처 조밀화(Prism/Inflation) | y+ 값 확인 |
| 경계조건 | Inlet(속도/유량), Outlet(압력) | 입출구 충분히 길게 |
| 수렴 판정 | Residual + 모니터 값 | 잔차 + 물리량 동시 안정 |

### 2.2 단계별 학습 계획 (약 4주)

**Week 1 — CFD 기초 감각**
- Day 1–2: 2D 원형 실린더 주위 유동 (Re에 따른 후류/와류)
  - 항력계수 Cd를 문헌값과 비교 (검증의 핵심)
- Day 3: 파이프 내부 유동 — 발달 유동, 압력강하를 Darcy 식과 비교
- Day 4–5: 메시 의존성 + 경계층(Inflation Layer) 생성 실습, y+ 확인

**Week 2 — 난류와 경계조건**
- 난류 모델 비교(k-ε vs k-ω SST) 동일 모델로 결과 차이 관찰
- Inlet/Outlet 조건 종류별 실습 (속도, 질량유량, 압력)
- 수렴 모니터 설정 — 관심 지점 압력/속도 추적

**Week 3 — 실전 내·외부 유동**
- 밸브/매니폴드 내부 유동 + 압력강하 계산
- 외부 유동(공력) — 단순 형상 항력/양력
- 회전 영역(MRF) — 팬/임펠러 기초

**Week 4 — 비정상 & 다물리**
- 과도(Transient) 해석 — 시간 스텝(CFL) 설정 감각
- 다상 유동 또는 자유표면 기초 (모듈 보유 시)
- **종합 과제**: 실제 유로 부품 1개 해석 + 압력강하/유량 검증 보고서

### 2.3 실용 팁
- **메시가 80%다** — 경계층 첫 셀 높이, prism 층수가 결과를 좌우
- 발산하면: ① 시간/완화계수 낮추기 ② 메시 품질(skewness) 점검 ③ 초기값 개선
- 입출구는 형상 특성길이의 **최소 5~10배** 확보 (역류 방지)
- 잔차가 떨어져도 **물리량(유량/압력)이 흔들리면 미수렴** — 둘 다 봐야 함

## 3. 열 해석 (Thermal Analysis)

구조와 연계가 많아(열응력) **세 번째로 학습**, 단 정상상태 전도는 쉬워 일찍 맛봐도 됨.

### 3.1 반드시 알아야 할 개념
| 개념 | 설명 | 체크 |
|------|------|------|
| 전도 (Conduction) | 푸리에 법칙, 열전도율 k | 접촉 열저항 고려 |
| 대류 (Convection) | 계수 h, 막온도 | h 추정이 정확도 좌우 |
| 복사 (Radiation) | 방사율 ε, 고온서 중요 | T⁴ 비선형 |
| 정상/과도 | Steady vs Transient | 비열·밀도 필요(과도) |
| 열-구조 연성 | 온도장 → 열응력 | 순차 연성 활용 |

### 3.2 단계별 학습 계획 (약 3주)

**Week 1 — 정상상태 전도/대류**
- Day 1–2: 1D 벽체 전도 — 해석적 온도분포와 비교
- Day 3: 대류 경계 추가 — 핀(Fin) 방열, 핀 효율 손계산과 비교
- Day 4–5: 접촉 열저항(Thermal Contact), 다층 벽 전도

**Week 2 — 복사 & 과도해석**
- 복사 경계조건 (표면-환경, 표면-표면)
- 과도 열해석 — 시간상수 τ, 냉각 곡선 추적
- 발열체(Heat Source/Generation) — 전자부품 냉각 모델

**Week 3 — 열-구조 연성 & 응용**
- 열응력(Thermal Stress) — 열해석 결과를 구조해석 하중으로 매핑
- CHT(Conjugate Heat Transfer) 기초 — CFD+열 (유동+고체 동시)
- **종합 과제**: 방열판/전장박스 1개 열해석 + 온도/열응력 보고서

### 3.3 실용 팁
- **대류계수 h 가 가장 큰 불확실성** — 문헌/실험/CFD로 합리적 값 확보
- 복사는 절대온도(K) 사용 필수 — 단위 실수 빈번
- 과도해석은 비열·밀도 누락 시 결과 무의미 → 물성 입력 재확인
- 열응력 연성: 온도장 매핑 후 **기준온도(Reference Temp)** 설정 확인

## 5. 학습 가속 체크리스트

### 매 해석마다 (Quality Gate)
- [ ] 단위계 일관성 확인했는가?
- [ ] 메시 수렴 확인했는가? (최소 2~3단계)
- [ ] 경계조건이 물리적으로 타당한가?
- [ ] 결과를 **이론/손계산/문헌/실험** 중 하나와 비교했는가?
- [ ] 평형(반력=외력 / 유입=유출 / 열입력=열출력) 만족하는가?

### 학습 효율 극대화
- **Verification Manual 따라하기** — NFX 검증예제는 정답이 있어 최고의 교재
- **실패 로그 모으기** — 발산/오류 메시지와 해결법을 노트화 (재발 방지)
- **동일 모델 다른 방법** — 같은 문제를 요소/모델 바꿔 풀며 차이 이해
- **MIDAS 기술지원/커뮤니티** 활용 — 막히면 빨리 질문
- **주 1회 복습 노트** — KK-NeroMind 마인드맵으로 개념 연결 정리

## 6. 분야별 추천 검증(벤치마크) 문제 모음

| 분야 | 벤치마크 | 비교 대상(정답) |
|------|----------|-----------------|
| 구조 | 외팔보 끝단 하중 처짐 | `PL³/3EI` |
| 구조 | 단순지지보 중앙 하중 | `PL³/48EI` |
| 구조 | 양단고정보 고유진동수 | 이론 모드 공식 |
| 유동 | 원형실린더 항력 | Cd–Re 문헌 곡선 |
| 유동 | 원관 층류 압력강하 | Hagen–Poiseuille |
| 유동 | 관마찰 | Moody 선도 |
| 열 | 1D 복합벽 전도 | 열저항 회로 |
| 열 | 직선핀 방열 | 핀 효율식 |
| 열 | 무한평판 과도냉각 | Heisler 선도 |

> 위 문제들을 **NFX로 직접 풀어 오차 5% 이내**로 맞출 수 있으면, 해당 분야 기초는 합격.

## 부록 A. 자주 하는 실수 Top 10
1. 단위계 혼용(특히 mm 단위에서 밀도/물성)
2. 메시 수렴 미확인 → 특이점 응력을 실제값으로 착각
3. CFD 경계층(prism) 누락 → y+ 과다 → 벽전단 부정확
4. 입출구 영역 짧음 → 역류/미수렴
5. 잔차만 보고 수렴 판정 (물리량 미확인)
6. 복사/과도에서 절대온도·물성(비열·밀도) 누락
7. 대류계수 h를 근거 없이 입력
8. 접촉/연결 조건 오류로 부품이 따로 노는 모델
9. 대칭 활용 안 해 해석 시간 낭비
10. 결과 검증(이론·실험 비교) 생략
