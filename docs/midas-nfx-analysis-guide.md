# Midas NFX 해석 역량 향상 가이드 (구조 · 유동 · 열)

> Ansys 대신 **Midas NFX** 를 활용해 구조 / 유동(CFD) / 열해석 실력을
> 실용적이고 빠르게 끌어올리기 위한 분야별 학습 계획서입니다.
> 각 분야는 **1) 개념 → 2) 툴 조작 → 3) 검증 예제 → 4) 실전 프로젝트**
> 순서로 단계를 밟도록 구성했습니다.

---

## 0. 시작 전 준비 (공통, 1주)

학습 효율을 좌우하는 것은 "해석 이론"보다 **워크플로우 습관**입니다.
Ansys 사용 경험이 있다면 NFX는 메뉴 구성과 솔버 철학이 다르므로,
먼저 NFX 특유의 흐름에 손을 익히는 것이 가장 빠른 길입니다.

### 0.1 환경 셋업 체크리스트
- [ ] Midas NFX 설치 및 라이선스(노드 락 / 네트워크) 확인
- [ ] 작업 단위계(SI: N, mm, ton, s 또는 N, m, kg, s)를 **하나로 고정**
- [ ] 결과 저장 폴더 / 프로젝트 네이밍 규칙 정하기 (예: `YYMMDD_부품_해석종류_rev`)
- [ ] 마우스 조작(회전·확대·패닝), 화면 분할, 결과 캡처 단축키 숙지

### 0.2 NFX의 기본 작업 흐름 (모든 해석 공통)
```
형상 import/모델링 → 재료 정의 → 메시 생성 → 경계조건/하중 →
해석 케이스(Analysis Case) 설정 → 솔버 실행 → 결과(Post) 확인 → 검증
```

### 0.3 Ansys 사용자가 NFX로 넘어올 때 매핑 표
| 개념 | Ansys | Midas NFX |
|------|-------|-----------|
| 작업 환경 | Workbench / APDL | 통합 GUI (전·후처리 일체형) |
| 메시 | Meshing 컴포넌트 | Mesh 탭 (Auto / Mapped) |
| 하중·구속 | Boundary Conditions | Static/Constraint 탭 |
| 해석 정의 | Analysis System | Analysis Case |
| 결과 | Mechanical / CFD-Post | Post 모드 (내장) |

> **핵심 차이**: NFX는 전처리·솔버·후처리가 **하나의 인터페이스**에 통합되어
> 있어 케이스 전환이 빠릅니다. 이 장점을 적극 활용하세요.

### 0.4 공통 학습 원칙
1. **항상 검증부터** — 손계산(보 처짐, 응력집중, 열저항)이 가능한 단순 모델로
   솔버 결과와 이론값을 비교해 "감"을 만든 뒤 복잡한 모델로 진행.
2. **메시 수렴성 확인 습관** — 메시를 2~3단계 세분화하며 결과 변화율 확인.
3. **한 번에 하나만 바꾸기** — 조건을 동시에 여러 개 바꾸면 원인 추적 불가.
4. **결과 기록** — 각 케이스의 입력/출력을 표로 남겨 재현성 확보.

## 1. 구조해석 (Structural) — 4주 집중

가장 직관적이고 검증이 쉬워 **첫 분야로 추천**합니다.

### Week 1 — 선형 정적 해석 기초
**목표**: 단순 형상에서 응력·변형을 정확히 예측하고 손계산으로 검증.

- 학습 개념: von Mises 응력, 주응력, 변형, 안전계수, 요소 종류(1D/2D/3D)
- 실습 예제 (난이도 순):
  1. 외팔보(Cantilever) 끝단 하중 → 처짐 `δ = PL³/3EI` 와 비교
  2. 단순지지보 중앙 집중하중 → 최대 굽힘응력 검증
  3. 구멍 뚫린 평판 인장 → 응력집중계수(Kt ≈ 3) 확인
- 검증 포인트: **이론값과 5% 이내** 일치하면 메시·조건이 올바른 것.

### Week 2 — 메시 품질과 수렴성
**목표**: "메시를 믿을 수 있는가"를 스스로 판단.

- 학습: 요소 크기, aspect ratio, Jacobian, 1차 vs 2차 요소
- 실습:
  - 응력집중부에서 메시를 단계적으로 세분화 → 수렴 그래프 작성
  - Mapped mesh vs Auto mesh 결과 비교
  - 대칭 조건 활용으로 모델 축소 (1/2, 1/4 모델)
- 산출물: **메시 수렴 곡선** 1장 (요소수 vs 최대응력)

### Week 3 — 조립체 · 접촉 · 볼트
**목표**: 실제 부품 수준의 다물체 해석.

- 학습: Contact(Bonded / Sliding / Friction), 볼트 프리텐션, 베어링 하중
- 실습:
  - 두 판 볼트 체결 모델 → 체결력에 따른 접촉압력 분포
  - 브래킷 + 볼트 조립체 정적해석
- 주의: 접촉 비선형은 수렴 실패가 잦음 → 하중 스텝 분할(Load step)로 해결

### Week 4 — 비선형 · 동해석 입문
**목표**: 선형의 한계를 넘는 해석 영역 경험.

- 모달 해석(Modal): 고유진동수·모드형상 → 공진 회피 설계
- 좌굴(Buckling): 임계하중 계수
- 비선형(재료/기하): 소성, 대변형
- 주파수 응답 / 과도 응답 입문(필요 시)
- 실습: 평판 모달 해석 → 이론 고유진동수와 비교

> **구조해석 4주 산출물**: 검증 예제 노트 + 실제 부품 1건 보고서
> (모델·조건·메시수렴·결과·결론 포함)

## 2. 열해석 (Thermal) — 3주 집중

구조해석 다음으로 진입을 권장합니다. 개념이 명확하고 손계산 검증이 쉽습니다.

### Week 1 — 정상상태 전도(Steady-State Conduction)
**목표**: 전도/대류/복사 경계조건을 정확히 부여.

- 학습 개념: 열전도율 k, 대류계수 h, 열저항 회로, 푸리에 법칙
- 경계조건: 고정온도(Temperature), 열유속(Heat Flux), 대류(Convection), 발열(Heat Source)
- 실습 예제:
  1. 1D 벽체 전도 → `q = kAΔT/L` 검증
  2. 핀(Fin) 방열 → 핀 효율 이론값과 비교
  3. 다층 벽(복합재) → 직렬 열저항 합산 검증

### Week 2 — 과도 열해석(Transient) + 대류·복사
**목표**: 시간에 따른 온도 변화 예측.

- 학습: 비열, 밀도, 시간 스텝, 초기온도, 복사율(emissivity)
- 실습:
  - 가열판 냉각 곡선 → 시정수 비교
  - 전자부품 발열 → 정상상태 도달 시간 산정
- 주의: 시간 스텝이 너무 크면 진동/부정확 → 안정성 확인

### Week 3 — 열-구조 연성(Thermal-Stress Coupling)
**목표**: 열변형·열응력 예측 (NFX의 강점 활용).

- 학습: 열팽창계수 α, 열응력 `σ = EαΔT`, 구속 조건의 영향
- 워크플로우: 열해석 결과(온도장) → 구조해석 입력으로 전달
- 실습:
  - 양단 구속 봉 가열 → 열응력 `EαΔT` 검증
  - 이종재료 접합부(바이메탈) 휨 변형
  - 발열 전자부품 + 방열판 열변형 평가

> **열해석 3주 산출물**: 정상/과도/연성 각 1건 검증 노트
> + 실제 발열 부품 열관리 보고서

## 3. 유동해석 (CFD) — 5주 집중

가장 난이도가 높고 검증이 까다로워 **마지막에 배치**합니다.
NFX의 CFD 솔버 특성(메시·난류모델·수렴 모니터링)에 충분히 시간을 투자하세요.

### Week 1 — CFD 기초 개념과 첫 해석
**목표**: 유동해석의 입력/출력과 수렴 개념 이해.

- 학습: 레이놀즈수, 층류/난류, 유입·유출 경계, 벽함수, 잔차(Residual)
- 실습:
  1. 2D 파이프 내부 층류 → 속도 분포(포물선) 및 압력강하 검증
     (Hagen–Poiseuille `Δp = 32μLV/D²`)
  2. 잔차 그래프 읽는 법 — 수렴/발산 판단

### Week 2 — 메시(유동 전용)와 경계층
**목표**: CFD 결과 신뢰성의 80%는 메시.

- 학습: 경계층 메시(Inflation/Prism layer), y+ 개념, 메시 독립성
- 실습:
  - 경계층 레이어 수에 따른 벽 전단응력 변화
  - 메시 독립성 시험(coarse/medium/fine)
- 산출물: **y+ 점검 결과** + 메시 독립성 표

### Week 3 — 외부 유동과 난류 모델
**목표**: 항력·양력 예측, 난류모델 선택 기준.

- 학습: k-ε, k-ω SST 등 난류모델 특징과 선택 기준
- 실습:
  1. 원통 주위 유동 → 항력계수 Cd 문헌값과 비교
  2. 에어포일/단순 차체 외부유동 → 항력·압력분포

### Week 4 — 열유동 연성(Conjugate Heat Transfer, CHT)
**목표**: 유동 + 열을 동시에 (NFX 핵심 활용처).

- 학습: 고체-유체 열교환, 강제대류 vs 자연대류
- 실습:
  1. 방열핀 강제대류 냉각 → 표면 대류계수 및 온도분포
  2. 전자기기 내부 공랭 → 부품 온도 예측
- 활용: 2장 열해석에서 가정했던 대류계수 h를 **CFD로 직접 산출**

### Week 5 — 실전 통합 프로젝트
**목표**: 실제 설계 문제를 처음부터 끝까지.

- 예: 펌프/밸브 내부 유동, 히트싱크 최적화, 외기 환기 설계 중 택1
- 절차: 형상 정리 → 메시 전략 → 경계조건 → 수렴 모니터링 → 결과 검증 → 설계 개선안
- 산출물: **CFD 보고서** (가정·검증·한계 명시)

> **CFD 5주 산출물**: 내부유동/외부유동/CHT 검증 노트 + 통합 프로젝트 1건

## 5. 빠른 습득을 위한 핵심 전략

1. **검증 주도 학습(Verification-Driven)**
   - 매 예제마다 손계산 또는 문헌값과 비교. "맞춘 경험"이 쌓여야 실력이 된다.
2. **나만의 검증 라이브러리 구축**
   - 외팔보·구멍판·핀·파이프유동 등 표준 예제를 NFX 파일로 보관 →
     새 버전/새 PC에서 솔버 검증용으로 재사용.
3. **체크리스트 사용**
   - 단위계 / 재료 물성 / 경계조건 / 메시품질 / 수렴 — 매번 같은 순서로 점검.
4. **에러·발산 로그 기록**
   - 수렴 실패 원인과 해결법을 모아두면 같은 실수를 반복하지 않는다.
5. **결과를 항상 의심**
   - "물리적으로 말이 되는가?"를 먼저 묻는다 (응력 방향, 열 흐름 방향, 유선).
6. **멀티피직스는 NFX의 강점**
   - 통합 환경에서 열-구조, 열-유동 연성이 수월하므로 적극 활용.

## 6. 흔한 실수와 대응

| 증상 | 원인 가능성 | 대응 |
|------|------------|------|
| 응력이 비현실적으로 큼 | 응력집중부 특이점(singularity) | 필렛 모델링, 응력선형화, 메시 평가 기준 변경 |
| 변형이 과도/0 | 구속조건 오류 | 강체 모드 점검(모달로 0 Hz 확인) |
| 해석 수렴 실패 | 접촉/비선형 과도한 스텝 | 하중 스텝 분할, 초기 접촉 안정화 |
| CFD 잔차 발산 | 메시 품질/시간스텝 | 메시 개선, under-relaxation, 시간스텝 축소 |
| 열응력 과다 | 비현실적 완전구속 | 실제 구속에 맞게 자유도 해방 |
| 결과 단위 이상 | 단위계 불일치 | 입력 단위계 재확인(특히 mm-ton-s) |

## 7. 학습 점검(자기평가) 기준

각 분야를 "습득"했다고 보려면:

- **구조**: 외팔보·구멍판 검증 5% 이내, 접촉 모델 수렴, 모달 1·2차 모드 설명 가능
- **열**: 1D 전도/핀 검증 통과, 과도 시정수 예측, 열응력 `EαΔT` 검증
- **유동**: 파이프 압력강하 검증, y+ 적정 범위 확보, 외부유동 Cd 문헌값 ±15% 이내, CHT 1건 완료

## 부록 A. 분야별 핵심 물성 입력 체크
- 구조: 탄성계수 E, 푸아송비 ν, 밀도 ρ, 항복강도(비선형 시)
- 열: 열전도율 k, 비열 cp, 밀도 ρ, 열팽창계수 α, 복사율 ε
- 유동: 밀도 ρ, 점성계수 μ, 비열·전도율(열유동 시)

## 부록 B. 추천 학습 자료 유형
- Midas NFX 공식 매뉴얼 / 튜토리얼 / 웨비나
- 검증용: 재료역학·열전달·유체역학 교과서의 해석해 예제
- 벤치마크: NAFEMS 표준 검증 문제(구조·열)
