## 1. 학습 전략 개요

### 핵심 원칙

| 원칙 | 설명 |
|------|------|
| **이론 30% / 실습 70%** | NFX는 직접 모델을 돌려보며 익히는 것이 가장 빠릅니다. 이론은 "왜 이 결과가 나왔는가"를 설명할 수 있을 만큼만. |
| **단순 모델 → 복잡 모델** | 손으로 계산 가능한 모델(외팔보, 평판, 1D 관로)로 시작해 **해석 결과를 손계산과 비교**하며 신뢰를 쌓습니다. |
| **검증(Verification) 우선** | 처음 3주는 새 기능보다 "정답을 아는 문제"를 풀어 NFX 사용법과 결과 해석을 동시에 학습합니다. |
| **에러 로그를 친구로** | Solver 메시지(.out, .log)를 읽는 습관이 실력의 분기점입니다. |
| **단위계 고정** | 프로젝트 시작 시 단위계(SI: N, mm, MPa, ton, s 또는 N, m, Pa)를 정하고 절대 섞지 않습니다. |

### NFX의 강점 활용

- **단일 통합 환경**: 전처리 → 솔버 → 후처리가 한 GUI 안에 통합되어 입문자 진입장벽이 낮음
- **구조 + 유동 + 열 + 다물리 연성**을 하나의 플랫폼에서 제공 → 분야 간 전환 학습 비용이 적음
- **한글 인터페이스 / 한글 매뉴얼** 지원 → 용어 학습 부담 완화
- **DesignX(형상 단순화), 자동 메시** 기능으로 전처리 시간 단축

## 2. 공통 기초 — 가장 먼저 다질 것

> 어느 분야를 하든 아래는 **공통 필수**입니다. (예상 소요: 3~5일)

### 2.1 인터페이스 & 워크플로우

- [ ] 작업 트리(Works Tree) 구조 이해: Geometry → Mesh → Material/Property → BC/Load → Analysis Case → Results
- [ ] 마우스 조작(회전/이동/확대), 단축키, 선택 필터(점/선/면/요소)
- [ ] 단위계 설정 및 확인 위치
- [ ] 결과 후처리: Contour, Probe, Path/Graph, 애니메이션, 결과 추출(CSV)

### 2.2 형상(Geometry) 다루기

- [ ] CAD 임포트(STEP/IGES/Parasolid) 및 형상 치유(Healing)
- [ ] **DesignX**로 불필요한 라운드/홀/디테일 제거(Defeaturing) — 메시 품질·해석시간에 직결
- [ ] 중립면 추출(Mid-surface) — 얇은 판재 구조의 쉘 모델링 핵심
- [ ] 분할(Imprint/Divide)로 하중·구속 영역 만들기

### 2.3 메시(Mesh) — 모든 해석의 정확도를 좌우

| 요소 | 용도 | 비고 |
|------|------|------|
| 1D (Beam/Bar) | 프레임, 트러스, 배관 | 단면 특성 정의 필요 |
| 2D (Shell/Plate) | 판재, 박판 구조 | 두께 방향 디테일 무시 가능할 때 |
| 3D (Tetra/Hexa) | 후육 솔리드, 복잡 형상 | Hexa가 정확도/효율 우수, Tetra는 자동화 용이 |

- [ ] **메시 의존성 테스트(Mesh Convergence)**: 요소 크기를 절반씩 줄이며 결과가 수렴하는지 확인 — *이걸 안 하면 모든 결과를 의심받습니다.*
- [ ] 1차 vs 2차 요소(중간절점) 차이 이해: 굽힘이 지배적이면 2차 요소 또는 충분한 요소층 필요
- [ ] 종횡비(Aspect Ratio), 비틀림(Skewness), Jacobian 등 품질 지표 확인
- [ ] 국부 세분화(Local Seeding/Sizing): 응력 집중부·박리 영역만 조밀하게

## 3. 구조해석 (Structural)

> **가장 먼저 시작하기 좋은 분야.** 손계산 검증이 쉽고 NFX의 진입장벽이 가장 낮습니다.

### 3.1 단계별 습득 로드맵

#### Level 1 — 선형 정적 (Linear Static) · 1주차

가장 기본이자 실무 80%를 차지합니다.

- **검증 예제 (반드시 손계산과 비교)**
  - 외팔보(Cantilever) 처짐: δ = PL³/3EI
  - 단순지지보 중앙 처짐/응력
  - 평판 인장 → σ = P/A, 변형률 = σ/E
  - 구멍 뚫린 판의 응력 집중 계수(Kt ≈ 3)
- **학습 포인트**
  - [ ] 경계조건(고정/대칭/롤러)의 물리적 의미와 과구속(Over-constraint) 주의
  - [ ] 하중 종류: 집중하중, 분포하중(Pressure), 중력, 원격하중(Remote Force)
  - [ ] 결과 해석: von Mises vs 주응력(Principal), 변위, 반력(Reaction) 합 = 외력 합 확인
  - [ ] 안전계수(Safety Factor) 산출

#### Level 2 — 모달 / 진동 (Normal Modes) · 2주차

- [ ] 고유진동수·모드형상 추출, 강체모드(0Hz 6개) 의미
- [ ] 검증: 외팔보 1차 고유진동수 이론식과 비교
- [ ] 주파수 응답(Frequency Response), 랜덤 진동(PSD) — 진동 환경 제품 필수
- [ ] 응답 스펙트럼(내진/충격)

#### Level 3 — 비선형 (Nonlinear) · 3~4주차

실무에서 "진짜 어려운" 영역. 천천히.

- [ ] **재료 비선형**: 탄소성(소성변형, 항복 후 거동), 재료 곡선 입력
- [ ] **기하 비선형**: 대변형/대회전(Large Displacement) — 얇은 구조, 좌굴 후 거동
- [ ] **접촉(Contact)**: 면-면 접촉, 마찰, 간극 — *수렴 실패의 단골 원인, 가장 많은 연습 필요*
- [ ] 좌굴(Buckling): 선형 좌굴 → 비선형 좌굴
- [ ] 수렴 전략: 하중 스텝(Load Step) 분할, 자동 시간증분, 접촉 안정화

#### Level 4 — 기타 실무 해석

- [ ] 피로(Fatigue): S-N 선도, 누적 손상(Miner), 내구 수명
- [ ] 열응력(Thermal Stress) → [6장 연성해석](#6-연성해석-coupled--multiphysics) 참고
- [ ] 복합재(Composite) 레이업, 용접/볼트 체결 모델링

### 3.2 빠른 습득 팁

1. **"답을 아는 문제"부터**: 재료역학 교과서 예제를 NFX로 재현 → 오차 5% 이내 목표
2. **반력으로 검증**: Σ반력 = Σ외력 이 안 맞으면 BC/하중이 틀린 것
3. **응력 집중부는 메시 수렴 필수**: 특이점(Singularity, 날카로운 모서리)에서는 응력이 발산하므로 라운드 처리 또는 공칭응력 평가
4. **단위 일관성**: MPa 결과가 비정상적이면 단위계부터 의심

## 4. 유동해석 (CFD / Flow)

> 3분야 중 **가장 까다롭습니다.** 메시·난류·수렴이 모두 얽혀 있어 "돌아가는 것"과 "맞는 것"의 차이가 큽니다.

### 4.1 단계별 습득 로드맵

#### Level 1 — 내부 유동 기초 · 1~2주차

- **검증 예제**
  - 원형관 층류(Hagen-Poiseuille): 압력강하 ΔP 이론식과 비교
  - 평판 위 경계층(Blasius 해)
  - 갑작스러운 확대/축소관, 엘보 압력손실
- **학습 포인트**
  - [ ] 유체 물성(밀도, 점성), 압축성 vs 비압축성 판단
  - [ ] 입구/출구 경계조건: Velocity inlet, Mass flow, Pressure outlet 조합 규칙
  - [ ] **레이놀즈 수(Re)** 계산 → 층류/난류 판정 → 모델 선택의 출발점
  - [ ] 벽면 조건(No-slip), 대칭면 활용으로 도메인 축소

#### Level 2 — 난류 모델 (Turbulence) · 3~4주차

CFD 정확도의 핵심.

| 모델 | 특징 | 추천 용도 |
|------|------|-----------|
| **k-ε (Standard/Realizable)** | 강건, 자유전단류 | 일반 내부유동, 초기 검토 |
| **k-ω SST** | 벽면 근처·박리 우수 | 외부유동, 박리·역압력구배 |
| RANS 일반 | 시간 평균 | 정상상태 대부분 |

- [ ] **y+ 개념과 벽함수(Wall Function)**: 첫 셀 높이가 결과를 좌우. y+ 목표값에 맞춰 경계층 메시(Inflation/Prism Layer) 설계
- [ ] 경계층 메시 5~10층 쌓는 연습 — *CFD 입문자가 가장 많이 놓치는 부분*
- [ ] 모델별 결과 비교 실험으로 감각 습득

#### Level 3 — 외부 유동 & 응용 · 5~6주차

- [ ] 외부 유동: 실린더/에어포일 항력·양력 계수(Cd, Cl) → 실험값과 비교
- [ ] 충분한 도메인 크기 확보(상류·하류·측면 여유), 원거리 경계조건
- [ ] 회전 기계(MRF/회전영역): 팬, 펌프 임펠러
- [ ] 다상유동(VOF, 자유표면), 비정상(Transient) 해석과 시간 스텝(CFL) 관리

### 4.2 빠른 습득 팁

1. **항상 정상상태(Steady) 먼저**: 수렴되면 그것을 초기값으로 비정상 해석 진행
2. **잔차(Residual)만 믿지 말 것**: 잔차가 떨어져도 틀릴 수 있음 → **관심 물리량 모니터(출구 유량, 항력)가 일정해질 때까지** 추가 확인
3. **질량 보존 체크**: 입구 유량 = 출구 유량 (오차 1% 이내)
4. **메시 수렴 + y+ 확인을 매번**: CFD 신뢰의 두 기둥
5. **수렴 안 되면**: ① 저속/저완화계수로 시작 ② 메시 품질 개선 ③ 경계조건 물리적 타당성 재점검

## 5. 열해석 (Thermal)

> 구조보다 직관적이고, 손계산 검증이 비교적 쉬워 **구조 다음으로 익히기 좋습니다.**

### 5.1 단계별 습득 로드맵

#### Level 1 — 정상상태 전도 (Steady-State Conduction) · 1주차

- **검증 예제**
  - 1D 평벽 전도: q = kA·ΔT/L (이론식 비교)
  - 복합벽(직렬 열저항), 원통/구 전도
  - 핀(Fin)의 온도 분포·방열량
- **학습 포인트**
  - [ ] 열전도율(k), 경계조건 3종: 고정온도(Dirichlet), 열유속(Neumann), 대류(Convection: h, T∞)
  - [ ] 발열(Heat Generation) 부여 — 전자부품, 발열체
  - [ ] 열저항 회로 개념으로 결과 손검증

#### Level 2 — 대류 & 복사 · 2주차

- [ ] **대류**: 열전달계수 h 산정(상관식 또는 CFD 연계), 자연/강제 대류 구분
- [ ] **복사(Radiation)**: 방사율(Emissivity), 형상계수(View Factor), 표면 간 복사
- [ ] 접촉 열저항(Contact Conductance) — 조립체 해석에서 중요

#### Level 3 — 과도 열해석 (Transient) · 3주차

- [ ] 비열·밀도(열용량), 시간 스텝 설정
- [ ] 검증: 라움프드 캐패시턴스(Lumped Capacitance)모델 — 비오 수(Bi) 작을 때 지수 응답과 비교
- [ ] 가열/냉각 곡선, 시간에 따른 온도 이력 추출
- [ ] 상변화(용융/응고) 등 고급 주제

### 5.2 빠른 습득 팁

1. **에너지 보존 체크**: 정상상태에서 들어온 열 = 나간 열
2. **h(대류계수)가 결과를 지배**: 모르면 CFD로 구하거나 상관식 여러 개 비교 (민감도 분석)
3. **단위 주의**: W, W/m²K, W/mK — 열해석은 단위 실수가 잦음
4. **열해석 → 구조(열응력) 연계가 실무의 단골**: [6장](#6-연성해석-coupled--multiphysics)으로 자연스럽게 확장

## 6. 연성해석 (Coupled / Multiphysics)

> NFX의 진짜 강점. 단일 환경에서 분야를 연결합니다. (각 분야 Level 2 이상 도달 후 진입 권장)

| 연성 유형 | 흐름 | 대표 응용 |
|-----------|------|-----------|
| **열-구조 (Thermal-Stress)** | 열해석 온도장 → 구조해석 하중 | 엔진, 전자부품, 용접 잔류응력, 금형 |
| **유동-열 (Conjugate Heat Transfer, CHT)** | 유체+고체 열전달 동시 해석 | 히트싱크, 냉각수로, 전자장비 방열 |
| **유동-구조 (FSI)** | 유체 압력 → 구조 변형 (단방향/양방향) | 밸브, 날개, 파이프 진동 |

### 학습 순서 추천

1. **열-구조**가 가장 쉽고 실용적 → 여기서 시작
2. **CHT**(유동-열) → 방열 설계 실무 직결
3. **FSI** → 가장 난이도 높음, 마지막

## 7. 12주 통합 학습 플랜

> 주당 8~10시간 투자 기준. 본인 업무 비중에 따라 분야 순서 조정 가능.

| 주차 | 주제 | 핵심 산출물 (검증 목표) |
|------|------|------------------------|
| **1** | 공통 기초 + UI/메시 | 외팔보 선형정적, 메시 수렴 그래프 작성 |
| **2** | 구조 Level 1 (선형정적) | 응력집중판 Kt≈3 재현, 반력 검증 |
| **3** | 구조 Level 2 (모달/진동) | 외팔보 고유진동수 이론 대비 오차 <3% |
| **4** | 구조 Level 3 (비선형/접촉) | 접촉 예제 수렴 성공, 탄소성 항복 거동 |
| **5** | 열 Level 1 (정상상태 전도) | 1D/복합벽 열저항 손계산 일치 |
| **6** | 열 Level 2~3 (대류·복사·과도) | 핀 방열량, 과도 냉각곡선 |
| **7** | 유동 Level 1 (내부유동) | 원형관 ΔP 이론 대비, 질량보존 확인 |
| **8** | 유동 Level 2 (난류·y+) | 경계층 메시 + y+ 목표 달성 |
| **9** | 유동 Level 3 (외부유동) | 실린더/에어포일 Cd 실험값 비교 |
| **10** | 연성 — 열-구조 | 가열된 부품 열응력 산출 |
| **11** | 연성 — CHT (유동-열) | 히트싱크 방열 + 온도장 |
| **12** | 종합 프로젝트 | 실제 부품 1개를 3분야로 분석·보고서 작성 |

### 단계별 마일스톤 기준

- **입문 졸업(4주)**: 선형정적·모달을 손계산과 5% 이내로 검증 가능
- **중급 진입(8주)**: 비선형/난류 등 분야별 "어려운 주제" 1개씩 통과
- **실무 적용(12주)**: 연성해석 1건 + 자기 업무 부품 분석 보고서 완성

## 8. 검증 · 디버깅 체크리스트

### 해석 전 (Pre-check)

- [ ] 단위계가 전 모델에서 일관적인가?
- [ ] 형상 단순화로 불필요한 디테일을 제거했는가?
- [ ] 메시 품질 지표(Aspect, Skew, Jacobian)가 양호한가?
- [ ] 경계조건이 물리적으로 타당한가? (과구속/부족구속 없음)

### 해석 후 (Post-check) — "결과를 믿기 전에"

| 분야 | 필수 검증 |
|------|-----------|
| 구조 | Σ반력 = Σ외력 / 변형 형상이 직관과 일치 / 응력집중부 메시 수렴 |
| 유동 | 입구유량 = 출구유량 / 잔차 + 물리량 모니터 수렴 / y+ 적정 |
| 열 | 입열 = 출열 (정상상태) / 온도 범위가 물리적으로 타당 |

### 자주 만나는 오류와 대처

| 증상 | 원인 후보 | 대처 |
|------|-----------|------|
| 응력이 비정상적으로 큼 | 특이점, 점하중, 과구속 | 라운드 처리, 분포하중, BC 재검토 |
| 변위가 발산 | 부족구속(강체모드), 단위 오류 | 구속 추가, 단위 점검 |
| 비선형 수렴 실패 | 접촉, 큰 하중스텝 | 스텝 분할, 접촉 안정화, 초기 간극 점검 |
| CFD 발산 | 메시 품질, 큰 시간스텝 | 완화계수↓, 메시 개선, CFL 관리 |
| 온도 비현실적 | h/k 오류, 단위 | 물성·경계조건 단위 재확인 |

## 9. 추천 자료 및 학습 루틴

### 자료

- **Midas NFX 공식 매뉴얼 / 튜토리얼** (한글 지원) — 기능별 검색 학습에 최적
- **Midas 웨비나 · 교육 영상** — 분야별 실습 따라하기
- **이론 교과서** (도구 무관, 원리 이해용)
  - 구조: 재료역학(Hibbeler/Gere), 유한요소법 입문(Logan)
  - 유동: 유체역학(White/Cengel), CFD 입문(Versteeg & Malalasekera)
  - 열: 열전달(Incropera)
- **검증 문제집**: NAFEMS 벤치마크 — 정답이 공개된 표준 문제로 도구 신뢰성 확인

### 주간 학습 루틴 (권장)

1. **이론 1시간**: 그 주 주제의 지배방정식·이론식 정리
2. **실습 4~6시간**: 검증 예제 → 손계산 비교 → 메시 수렴
3. **응용 2시간**: 자기 업무 부품에 적용 시도
4. **기록 1시간**: 모델 설정·오차·삽질 내용을 노트로 정리 (← 이게 복리로 쌓입니다)

### 실력 향상의 3가지 습관

1. **항상 검증부터**: 새 기능은 "답을 아는 문제"로 먼저 익힌다
2. **메시 수렴을 매번**: 수렴 안 한 결과는 결과가 아니다
3. **오답 노트**: 수렴 실패·이상 결과의 원인과 해결을 누적 기록 → 같은 실수 반복 방지

---

> **요약**: `구조 → 열 → 유동 → 연성` 순서로, 각 분야를 **손계산으로 검증 가능한 단순 문제**부터 시작해 메시 수렴과 에너지/힘 보존을 매번 확인하는 습관을 들이면, 12주 안에 NFX로 3분야 기본 해석을 자신 있게 수행할 수 있습니다.
